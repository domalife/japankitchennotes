Privacy Policy

Japan Kitchen Notes · Last updated 27 August 2026

Summary

This site is a set of static pages. It has no accounts, no login, no comment form and no newsletter. It does not collect personal information from visitors.

The site

  • No cookies are set by this site.
  • No analytics or tracking scripts are used.
  • The pages are hosted on GitHub Pages, which records standard server access logs. Those logs are handled by GitHub under its own privacy policy, and are not accessible to this site's operator in an identifiable form.

Affiliate links

Some outbound links are affiliate links. When you follow one, the destination retailer or its affiliate network may set cookies in order to attribute a purchase. That processing is carried out by those companies under their own privacy policies. This site receives only aggregate reports — counts of clicks and orders — and never the identity, address or payment details of a buyer.

The Pinterest application

A private application is used to publish original graphics to the operator's own Pinterest boards through the Pinterest API.

  • It authenticates one account: the operator's own, through Pinterest's standard OAuth flow.
  • It does not offer sign-in to anyone else, and it does not read or store data belonging to other Pinterest users.
  • The access token is stored locally on the operator's own computer and is not transmitted anywhere except to Pinterest.
  • The only data sent to Pinterest is the content being published: an image, a title, a description and a destination link.

Children

This site is not directed at children and does not knowingly collect information from them.

Changes

If this policy changes, the revised version will be posted on this page with a new date.
